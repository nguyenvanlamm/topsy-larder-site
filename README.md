# topsy-larder-site

Trang giới thiệu của **Topsy Larder** (game puzzle iOS): `index.html`, chính sách quyền riêng tư `privacy.html` và hỗ trợ
`support.html` (URL dùng cho App Store Connect). Xuất bản bằng GitHub Pages từ nhánh `main`, thư mục gốc; mỗi lần push lên
`main` là trang được cập nhật. Không có GitHub Actions.

- Site: https://nguyenvanlamm.github.io/topsy-larder-site/
- Ảnh trong `assets/` lấy từ `screenshots/` và icon của repo game `topsy-larder`.
